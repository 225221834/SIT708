# LLM Chatbot

A modern Android app built on Java that does a chat conversion with cloud Gemini AI, it features a real-time conversion. An implementation of how AI can be used as a service. Its for the project SIT708 Task 8.1C

## Getting Started

### Prerequisites
- Android Studio Panda 2 or newer

### Steps
1. Clone the repository
2. Open in Android Studio
3. Sync project with Gradle files
4. Run on device or emulator

## Tech Stack
- Java
- XML
